# VibePet 功能清单

> 版本：v1.0.5 | 作者：YTU22 | 仓库：https://github.com/YTU22/vibepet

---

## 一、核心功能

### 1.1 软件使用时长监测
- **前台进程追踪**：每 2 秒检测一次当前活动窗口进程
- **智能进程归一化**：自动合并浏览器（Chrome/Edge/Firefox 统一为 browser）、IDE（PyCharm64→pycharm 等）
- **四分类体系**：办公(work)、游戏(game)、休闲(leisure)、其他(other)
- **空闲检测**：基于 `GetLastInputInfo`，5 分钟无输入判定为 idle
- **内存缓存 + 定时落盘**：每 60 秒批量写入 SQLite，减少磁盘 IO

### 1.2 健康提醒引擎
- **规则表达式驱动**：支持安全 `eval` 条件表达式，可自定义阈值与优先级
- **5 大内置规则**：
  | 规则 | 触发条件 | 提醒方式 | 动画 |
  |------|---------|---------|------|
  | 游戏沉迷 | 游戏累计 ≥ 120 分钟 | 气泡 + Toast | tired |
  | 久坐提醒 | 连续活跃 ≥ 60 分钟 | 气泡 + Toast | tired |
  | 深夜防熬夜 | 23:00-06:30 持续使用 ≥ 30 分钟 | 气泡 + Toast | sleep |
  | 正向激励 | 游戏→工作切换后持续 ≥ 5 分钟 | 气泡（无 Toast） | happy |
  | 每日疲劳 | 当日总时长 ≥ 8 小时 | 气泡 + Toast + 警告弹窗 | angry |
- **30 分钟冷却期**：同规则触发后 30 分钟内不再重复提醒
- **Windows Toast 通知**：调用 `win10toast` 异步显示系统通知

### 1.3 随机情绪系统
- **三时段概率模型**：
  - 白天(06-18)：sleep 2% / happy 15% / tired 3%
  - 傍晚(18-22)：sleep 5% / happy 10% / tired 8%
  - 深夜(22-06)：sleep 20% / happy 5% / tired 15%
- **每 10 秒概率检查**，触发后持续 15-60 秒随机时长
- **情绪优先级**：规则触发 > happy 激励 > work 状态 > 随机情绪 > idle

## 二、宠物交互

### 2.1 动态效果
- **呼吸浮动**：正弦曲线，2 秒周期，上下浮动 8 像素，20fps
- **眨眼动画**：每 4 秒触发，图片纵向压扁至 95% 后恢复
- **点击摇晃**：点击宠物触发左右摇晃 2 次，带弹性缓动曲线
- **拖拽跟随**：按住宠物可拖拽到任意位置

### 2.2 气泡交互
- **提醒气泡**：白色圆角气泡，自动计算宽高，最大宽度适配窗口
- **应用追踪气泡**：右上方迷你气泡，实时显示当前活动应用名称
- **气泡透明度**：支持 0.3-1.0 滑块调节
- **自动隐藏**：气泡显示 3-8 秒后渐隐

### 2.3 状态动画
- 支持 6 种状态 PNG 切换：idle / work / happy / tired / sleep / angry

## 三、系统监控面板

### 3.1 监控指标
| 指标 | 采样方式 | 显示格式 |
|------|---------|---------|
| CPU | `psutil.cpu_percent(interval=0.5)` 阻塞精确采样 | 百分比 + 颜色阈值 |
| 内存 | `psutil.virtual_memory()` | 百分比 + 颜色阈值 |
| 磁盘 IO | `disk_io_counters()` 差值法 | 自动 B/KB/MB/s |
| 网速 | `net_io_counters()` 差值法，过滤虚拟网卡 | 自动 B/KB/MB/s |
| GPU | NVIDIA NVML(ctypes) / AMD&Intel(win32pdh) | 百分比 + 颜色阈值 |

### 3.2 面板特性
- 位于宠物左侧，垂直居中
- 彩色阈值：绿色(<30%) / 黄色(30-80%) / 红色(>80%)
- 可配置显示项与刷新间隔（默认 1-2 秒）

## 四、统计看板

### 4.1 数据可视化
- **柱状图**：今日使用时长 Top 10 应用（分钟）
- **饼图**：今日软件使用分类占比（work/game/leisure/other）
- **实时时钟**：顶部显示当前时间，每秒刷新

### 4.2 数据导出
- **CSV 导出**：一键导出全部历史数据为 CSV 文件

## 五、设置面板（6 个 Tab）

### 5.1 提醒设置
- 5 大健康提醒的独立开关
- 各规则阈值调节（滑块/数字输入框）
- 一键恢复默认提醒设置

### 5.2 外观设置
- 宠物尺寸：80-400px 滑块调节
- 气泡透明度：0.3-1.0 滑块
- 启动时是否显示宠物

### 5.3 情绪设置
- 随机情绪总开关
- 三时段（白天/傍晚/深夜）各情绪概率自定义
- 一键恢复默认情绪概率

### 5.4 进程分类
- **分类列表编辑**：work / game / leisure / other 四类应用名单文本编辑
- **自定义分类**：支持添加/删除/重命名自定义分类
- **未分类进程检测列表**：
  - 实时列出检测到但未分类的进程
  - 快捷键快速分类：W-办公 / G-游戏 / L-休闲 / O-其他 / Del-移除
  - 多选支持，批量分类

### 5.5 系统监控
- 监控总开关
- 各指标（CPU/内存/磁盘/网络/GPU）独立显示开关
- 刷新间隔调节（1-10 秒）

### 5.6 关于
- 版本号显示
- 作者信息
- **GitHub 项目链接**：点击可跳转浏览器
- **检测更新按钮**：手动检查 GitHub Releases 最新版本
- 开机自启动开关

## 六、系统托盘

  - 完全退出

- **双击托盘**：快速显示/隐藏宠物

## 七、窗口管理

### 7.1 基础特性
- **无边框置顶窗口**：`FramelessWindowHint + WindowStaysOnTopHint + Tool`
- **透明背景**：`WA_TranslucentBackground`，PNG 图片直接渲染
- **窗口尺寸**：80-400px 可调

### 7.2 高级特性
- **锁定位置**：禁止拖拽，固定在当前位置
- **鼠标穿透**：`WS_EX_TRANSPARENT`，点击穿透到下层窗口
- **位置记忆**：关闭时保存坐标，下次启动恢复（首次启动默认右下角）

---

## 八、数据管理

### 8.1 数据库
- **SQLite 本地存储**：`usage.db`，按日期+进程名聚合
- **WAL 模式支持**：提升并发性能
- **ON CONFLICT 增量更新**：重复进程自动累加时长

### 8.2 自动清理
- **30 天数据归档**：自动清理超过 30 天的详细数据
- **VACUUM 优化**：清理后执行数据库压缩

### 8.3 配置热重载
- **mtime 检测**：每轮监控循环检查 `config.json` 修改时间
- **自动重载**：外部修改配置后无需重启即时生效
- **缺失键填充**：自动补全新增的默认配置项

---

## 九、系统集成

### 9.1 开机自启动
- **注册表写入**：`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
- **多入口控制**：托盘菜单、设置页面、同步修复

### 9.2 首次运行引导
- **桌面快捷方式**：首次启动自动创建 `VibePet.lnk`
- **图标自定义**：使用 `assets/icon.png` 作为快捷方式图标

### 9.3 单实例保护
- **QLockFile 文件锁**：防止重复启动
- **重复启动提示**：弹出警告对话框，引导用户查看托盘

### 9.4 异常处理
- **全局异常钩子**：捕获未处理异常并写入日志
- **DummyStream**：防止 headless 模式下 stdout/stderr 崩溃
- **分级日志**：INFO/WARNING/ERROR/CRITICAL 写入 `vibe_pet.log`

---

## 十、检测更新

### 10.1 自动检测
- **启动后 5 秒延迟检查**：避免影响启动速度
- **GitHub Releases API**：`api.github.com/repos/YTU22/vibepet/releases/latest`
- **版本号对比**：支持 `x.y.z` 三段式语义化版本比较

### 10.2 手动检测
- 设置 → 关于 → "🔍 检测更新" 按钮
- 检测中显示加载状态
- 结果反馈：已最新 / 发现新版本（附带下载链接）/ 网络失败
